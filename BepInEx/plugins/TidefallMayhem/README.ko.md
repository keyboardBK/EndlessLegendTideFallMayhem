# Tidefall Mayhem 0.5.0 — 실버 / 골드 / 프리즘

총 36계열 × 3등급 = 108종입니다. 기본 효과는 기존 1.5배 강화를 유지하며, 아래 2026-11-02 조정 대상 5종은 지정한 실버 수치를 사용합니다. 효과 수치와 한국어·영어 설명, 비교 CSV에 함께 반영됩니다.

| 등급 | 실버 대비 효과 수치 | 선택창 등장 확률 |
| --- | --- | --- |
| 실버 | 1배 — 현재 실버 기준 | 40% |
| 골드 | 2배 | 40% |
| 프리즘 | 3배 | 20% |

예: 광란의 피해 보너스는 실버 +52.5%p / 골드 +105%p / 프리즘 +157.5%p입니다. 거인의 최대 체력은 +60% / +120% / +180%, 질주의 지상 이동력은 +3 / +6 / +9입니다.

한 번의 선택창에서 등급 하나를 뽑고, 그 등급의 서로 다른 증강 후보 3개를 표시합니다. 선택지 이름과 이벤트 제목에 등급을 표시합니다. 후보 조합은 등급별 96개씩 총 288개입니다. 확률은 각 선택창의 등급 추첨 확률이며, 개별 증강이 등장할 확률과는 다릅니다.

## 비교 CSV

이 폴더의 `augments.csv`를 Excel 또는 텍스트 편집기로 여세요. 같은 기본 증강의 실버·골드·프리즘이 연속으로 배치됩니다.

열: ID / 증강명 / 분류 / 효과 / 등급 / 영구중첩 / 기본증강ID / 실버대비배율 / 등급등장확률(%)

한글 Excel용 UTF-8 BOM입니다. CSV는 조회용이며, CSV만 바꿔도 게임 데이터가 변경되지는 않습니다. 효과 원본은 `Mods/TidefallMayhem.Plugin/augments.json`입니다. 기본 효과 배율은 `tiers.py`의 `EFFECT_MULTIPLIER=1.5`이며, 개별 조정 대상은 `effect_multiplier=1.0`으로 실버 수치를 직접 지정합니다. 등급 배율도 `tiers.py`, 추첨 로직은 `TieredDrafts.cs`입니다. 실버대비배율 열의 1/2/3은 현재 실버를 기준으로 합니다.

## 기존 규칙과 저장

- 플레이어만 증강을 받습니다. AI에는 증강 이벤트가 발생하지 않습니다.
- 시작 시 바로 첫 증강을 선택하고, 이후 매 Tidefall마다 추가 선택합니다.
- 켜기/끄기 선택창과 수동 이벤트 재호출은 없습니다.
- 다른 등급을 골라도 기존 증강은 없어지지 않으며, 모두 영구 누적됩니다.
- 예전 증강 36종의 ID를 유지해 기존 중첩은 실버로 취급합니다. 기존 중첩용 효과 데이터에도 현재 수치를 반영합니다.
- 내부 카운터 범위는 증강·등급별 65,535이며, 최종 능력치는 게임 자체 수치 범위에 따릅니다.
